# Exemplos — Auditoria de Post do LinkedIn

## Exemplo

> Entrada: "No mundo acelerado de hoje, as empresas estão fundamentalmente alavancando IA para desbloquear um ROI massivo — aqui está o que aprendi..."

> Saída:
> - **REPROVADO** (3 bloqueios)
> - L1 "No mundo acelerado de hoje" (abertura de preenchimento)
> - L1 "fundamentalmente" (vocabulário de IA)
> - L1 "alavancando" (vocabulário de IA)
> - L1 travessão `—`
> - **Reescrita sugerida:** "As empresas estão usando IA para cortar custos em 40%. Aqui está o que aprendi."
